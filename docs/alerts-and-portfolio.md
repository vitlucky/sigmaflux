# Alerts & Demo Portfolio — SigmaFlux

## Smart-алерты

Типы (MVP, детерминированные):

| Тип | Условие | Заметки |
|-----|---------|---------|
| `PRICE_ABOVE` | цена ≥ порога | manual / Smart (объём+волатильность) |
| `PRICE_BELOW` | цена ≤ порога | manual / Smart |
| `DROP_PCT_DAY` | падение за день ≥ N% | manual / Smart (ATR+волатильность) |
| `RISE_PCT_DAY` | рост за день ≥ N% | manual / Smart |
| `DROP_PCT_15M` | падение за 15 мин ≥ N% | manual / **Smart**: ATR·1.2, волатильность ≥1%, объёмный спайк ≥1.8×, ликвидность, торговое время |

Smart mode **live** (с этого этапа): учитывает ATR (средний true range по тикам), волатильность (std dev доходностей), объёмный спайк, ликвидность, торговое время MOEX (пн-пт 10:00–18:50 MSK) и наличие новости. Неподтверждённая новость блокирует Smart-триггер. Demo-данные не триггерят Smart. Переключатель Smart — в диалоге создания алерта (More → + Алерт → Smart).

Алерты живут локально (DataStore, `isSmart` флаг), срабатывание одноразовое (`active=false`, `fired_at`).
При обновлении котировок на главном экране алерты проверяются через `PriceHistoryRepository` (персистентный стор).

**Персистентный тиковый стор** (с этого этапа): `PriceHistoryRepository` (DataStore `price_history`, JSON `Map<symbol, List<PriceTick>>`, окно 15 мин, TTL + чистка, survives restart). Ранее — in-memory `QuoteRepository.history`. Теперь история переживает перезапуск, заполняется при первом `refresh()` и каждом обновлении. Fallback для тестов — in-memory.

## Демо-портфель

Создание: название, валюта (RUB/USD/USDT), стартовый баланс. Всё помечено SIMULATION.

Исполнение:
- MARKET: немедленно по последней цене ± проскальзывание 0.05%;
- LIMIT: исполняется по лимитной цене, если пересекает рынок; иначе остаётся OPEN;
- комиссия по умолчанию 0.3% от объёма (настраивается в портфеле).

Расчёты: средняя цена (avg price), realized P&L (при продаже), unrealized P&L (по текущим ценам),
allocation (cash + позиции), история сделок. Benchmark — позже.

Ограничения MVP: без шортов (продажа без позиции не исполняется), без дробных лотов
(проверка лотности — следующий этап); 15-минутные алерты теперь — персистентные (DataStore), окно не сбрасывается после перезапуска. Benchmark — следующий этап.
