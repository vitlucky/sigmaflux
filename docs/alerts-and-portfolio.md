# Alerts & Demo Portfolio — SigmaFlux

## Smart-алерты

Типы (MVP, детерминированные):

| Тип | Условие | Заметки |
|-----|---------|---------|
| `PRICE_ABOVE` | цена ≥ порога | manual threshold |
| `PRICE_BELOW` | цена ≤ порога | manual threshold |
| `DROP_PCT_DAY` | падение за день ≥ N% | manual threshold |
| `RISE_PCT_DAY` | рост за день ≥ N% | manual threshold |
| `DROP_PCT_15M` | падение за 15 мин ≥ N% | требует тикового среза — в MVP не оценивается, помечено |

Smart mode (следующий этап) учитывает: ATR, обычную волатильность, rolling returns, объём,
ликвидность, торговое время, наличие новости. Неподтверждённая новость не может сама по себе
создать сильный сигнал или critical push.

Алерты живут локально (DataStore), срабатывание одноразовое (`active=false`, `fired_at`).
При обновлении котировок на главном экране алерты проверяются автоматически.

## Демо-портфель

Создание: название, валюта (RUB/USD/USDT), стартовый баланс. Всё помечено SIMULATION.

Исполнение:
- MARKET: немедленно по последней цене ± проскальзывание 0.05%;
- LIMIT: исполняется по лимитной цене, если пересекает рынок; иначе остаётся OPEN;
- комиссия по умолчанию 0.3% от объёма (настраивается в портфеле).

Расчёты: средняя цена (avg price), realized P&L (при продаже), unrealized P&L (по текущим ценам),
allocation (cash + позиции), история сделок. Benchmark — позже.

Ограничения MVP: без шортов (продажа без позиции не исполняется), без дробных лотов
(проверка лотности — следующий этап), 15-минутные алерты требуют тикового хранилища.

## Никогда

- Никаких обещаний доходности;
- никакого «real-time» на demo-данных;
- никаких торговых рекомендаций в сигналах.
