# Visual Design — Graphite Premium

Зафиксировано пользователем. Не возвращать фиолетовые круги и яркую синюю клетку.

## Палитра

| Роль | Hex | Использование |
|------|-----|---------------|
| Background | `#16161C` | глубокий графит, фон |
| Surface | `#1A1A22` | карточки |
| Elevated | `#23232D` | поднятые элементы |
| Text | `#F2EFF7` | основной текст |
| Muted | `#A49EB0` | вторичный текст |
| Accent | `#B7A1FF` | мягкий фиолетовый акцент (действия, активные вкладки) |
| Positive | `#87D5B6` | muted mint — рост |
| Negative | `#E9A0B0` | muted rose — падение |
| Warning | `#D8B875` | amber caution — предупреждения, demo-метки |
| Danger | `#E4574F` | критическое событие, ошибка, остановка данных (красный — только тут) |

Минимум яркого синего. Тонкая material depth, карточки отделены от графика.

## Источники новостей (тихие метаданные)

На карточке НЕ показывать тяжёлые badges. Вместо этого: «ЦБ РФ · 18 мин •» + маленькая точка:

| Тир | Точка | Цвет |
|-----|-------|------|
| Официальный | muted blue/neutral dot | `#8FA6C7` |
| Профессиональное СМИ | gray-blue dot | `#7C7F9E` |
| Непроверенный (Telegram) | tiny amber dot | `#D8B875` |

Слово «Неподтверждено» — только на detail-экране или в фильтрах.

## Фон графика

`res/drawable-nodpi/graphite_material_bg.png` — диагональный полнотелый серый bullish-chart фон
с едва видимой технической сеткой. Генерируется скриптом (см. `create_*` в истории); в этом
реконструированном репозитории PNG создан программно и лежит в drawable-nodpi.

## Состояния UI (обязательны)

- skeleton loading;
- offline cache («показываем сохранённые данные»);
- stale data (метка «Данные устарели (N мин)»);
- provider error (без HTTP-кодов: «Источник временно ограничил запросы…»);
- empty state;
- AI disabled state (`AI_ENABLED=false`).
